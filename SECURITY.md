# Security Policy

Security and privacy are core principles at Moon Technologies. Thank you for helping keep our users safe.

## Reporting a vulnerability

Please **do not** open a public issue. Instead, use GitHub's private reporting:
open the affected repository → **Security** → **Report a vulnerability**.

Include what you found, how to reproduce it, the affected version and the possible impact.

## What to expect

- Acknowledgement within **5 working days**.
- An assessment and, when confirmed, a plan and timeline for the fix.
- Credit in the release notes if you wish.

## Supported versions

Unless a project says otherwise, only the latest release receives security fixes.
